# 📝 Full-Stack To-Do App with Authentication

A clean, modern, and secure **To-Do List application** designed to help users manage their tasks effectively. This project is built as a complete full-stack solution, ensuring data integrity and a smooth user experience through personalized accounts.

---

## ✨ Key Features

* **Secure User Authentication:** Implements safe sign-up and log-in functionality.
* **Personalized Task Management:** Each user has their own private list of tasks that only they can access.
* **CRUD Operations:** Full functionality to **Create**, **Read**, **Update**, and **Delete** your to-do items.
* **Intuitive Interface:** A responsive and easy-to-use design for smooth task handling.

---

## 🛠️ Technology Stack

This application uses a modern, divided architecture with a dedicated frontend and backend.

### Core Technologies

* **Primary Language:** TypeScript (for robust and scalable code)
* **Structure:** Separate `frontend` and `backend` modules (Full-Stack)
